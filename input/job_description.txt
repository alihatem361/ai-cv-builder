Role Description

This is a full-time hybrid role for a Frontend Developer specializing in React and Next.js with 4 years of experience. The role is based in Cairo, Egypt, with an option for partial remote work. The developer will be responsible for designing and implementing responsive web interfaces, collaborating with back-end developers to integrate APIs, optimizing application performance, and maintaining software quality through regular testing and debugging. Additionally, the developer will participate in team meetings to contribute ideas for project development and improvement.

Ability to work both independently and collaboratively in a hybrid work environment
